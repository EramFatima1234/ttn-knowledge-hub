# Folder Structure

```
ttn-knowledge-hub/
├── apps/web/           # Next.js UI
├── apps/api/           # NestJS API + prisma/
├── packages/types/     # Shared types
├── docs/               # Engineering docs
├── architecture/       # Flow diagrams
├── adr/                # Decision records
├── roadmap/            # Planning
├── onboarding/         # This folder
├── ai/                 # AI prompt library for humans
└── .cursor/            # Cursor agent knowledge base
```

Feature code: `apps/web/src/features/<name>/`. API: `apps/api/src/modules/<name>/`.
