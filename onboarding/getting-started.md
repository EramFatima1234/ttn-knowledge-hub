# Getting Started

1. Read `README.md` and run setup (`docs/setup-guide.md`).
2. Read `docs/project-overview.md` and `architecture/system-overview.md`.
3. Sign in with Google `@tothenew.com`; ask admin for TEAM/ADMIN if needed.
4. Run `pnpm dev` — web :3000, API :3001.

New developers: `onboarding/folder-structure.md`, `onboarding/development-workflow.md`.
