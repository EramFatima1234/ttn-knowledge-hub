# Glossary

| Term | Meaning |
|------|---------|
| Knowledge Meet | Recorded monthly-style session; model `KnowledgeMeet` |
| Knowledge Series | Ordered collection of episodes (`SeriesSession`) |
| Content Manager | Admin CMS UI at `/admin/content` and API `admin/cms` |
| Aspire | Pink/purple internal theme (`knowledgehub.scss`) |
| TEAM | Role for contributors (upload, studio) |
| CMS metadata | `homepageTags`, `displayPriority`, URL preview fields |
| Continue watching | `History` rows surfaced via engagement API |
| Adapter | Env-selected implementation (storage, search, mail, push, AI) |
| Transform interceptor | Wraps API JSON responses in consistent envelope |
